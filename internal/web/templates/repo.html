Password kept by the owner

BelayPoint has no password for this repository on purpose, so it is not reported as missing one. Without the password it can still show:

  • the size (Storage) and the lock files,
  • the number of snapshot files and when the newest was written, that is when the repository was last appended to. If that is longer ago than 7 days, the overview suggests asking the owner whether they still need it or need help.

It cannot list or check snapshots, run forget, prune or check, or remove locks. The repository only grows: clients write append-only, so the owner cannot delete anything through the rest-server either. To clean up, the owner needs to share the password for a while (or run forget/prune through a rest-server without --append-only).
